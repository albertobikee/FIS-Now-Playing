# Media

- `photos/` → JPG/PNG (ideally < 1 MB each / idealmente < 1 MB cada una)
- `videos/` → short MP4 clips / clips MP4 cortos

🇬🇧 Videos stored in the repo do not play inside the README. To get an inline player, drag the MP4 (max. 10 MB on a free account) into the README editor on github.com and GitHub inserts a link that plays in the page.

🇪🇸 Los vídeos guardados en el repo no se reproducen dentro del README. Para tener reproductor, arrastra el MP4 (máx. 10 MB en cuenta gratuita) al editor del README en github.com y GitHub inserta un enlace que se reproduce en la página.
